# Routing & shared UI

**Files:** `js/app.js` (`/* ---------- Yönlendirme` ~L370, helpers L37–370, Lia/theme ~L5328–5455, Başlat ~L17081), `index.html`.

## How it works
- Hash routes `#/<name>/<id>/<extra>` → `parseRoute()` → `render()` switch. `render()` resets `view.onclick/onchange`, removes sheets, stops play/bot timers, page-in animation, `syncMusic()`, `histPush()`, `drawHelper()`.
- Full-screen (no nav): `p`, `chat`, `create/<id>`.
- Edit-mode gate: `create` and `monia` require `editOn()` (Ben → ⚙️ Ayarlar → ✏️); otherwise redirect to `#/me`.

- ⚡ Perf memo (v1088): `tickGet(key, fn, sig)` caches a value for the current task (setTimeout 0 clears it; `save()` clears it; a changed `sig` array, compared by `===`, rebuilds). Used by `moCats` (also `catMemo` string signature + `catMemo.byId` for `catOfEv`), `allEvents`, `evById` / `feelEvents`, `evFind`, chat `actEv` / `actOpen`. Hot path rule: never call `allEvents()` / `moCats()` + `toLocaleLowerCase` inside a per-event loop; build a Map once. v1095: use `lowTr(s)` (memoized tr-lowercase + trim) and `evByLowTitle(lowTitle)` (title → first event) instead of `allEvents().find(e => low(e.title) === …)` — that pattern made first boot ~68 s and froze iPhone on the splash. Never pass `[allEvents()]` as a `tickGet` sig (new array every call).

## Change safety
- New page = add `case` in `render()` + `renderX()` + (optionally) `HELP` entry, nav/booble link, book chapter.
- Pages must set `view.onclick` themselves (render clears it).
- 🧘 Global toggle Sade mesajlar `simpleOn` (`amor-stories:simple`, default on; Ben → Ayarlar, visible without edit mode) → chat.md.
