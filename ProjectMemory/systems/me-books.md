- 🗺️ Görevler tab (`gorev`, after 📊 Özet; `meQuests`, next to `meSummary`): branching quest tree. `QUESTS` rows `[id, branch, icon, title, desc, need[], check(x) → [cur, max], go link, pay ₺]`, branches `QBR` (v885: fant branch + 🐍/💍 `gizli1 → izsiz / yakalandin → sonkarar`, `anlasma → ucyuzuk`, QC `affair/affst/bullst`); a quest opens when all `need` are done, indented by depth inside its branch. `questCtx()` derives progress from existing data: events done = all threads' `th.evDone` + `m.ev` (by title via `ev(...)` or by category via `cat(k)`, ids in `QC`, places `QPLACES`), ❓ questions from `u.qAsk` (rule name base → id, written by `questAsk` in botReply where `isQ`; `QBODY` / `QEXP` id regexes), sites/subs/orders/res/preg/games like the badges. `questSync(say)` writes `u.quests[id] = { at }` (stays even if data is deleted), runs on every route change (🗺️ notify, one combined if several) and in `meQuests`. 🎁 `data-qpay` (or `*` = all) → `bankAdd`, `paid: true`. Styles are an inline `<style>` in the tab (CSS vars, so dark mode works; also the tab's show rule). EN strings in `i18n-en-ui2.js`. New quest = one `QUESTS` row (+ EN dictionary lines); a renamed event title / category id breaks its check silently.
